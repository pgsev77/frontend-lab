## 推荐学习顺序

**第一遍（建主线，按视图/状态两条轴走）：**
`01-1 视图基础` → `01-2 组件化` → `01-4 渲染机制`（打通视图轴"描述→组织→渲染"）→ `01-5 状态管理` → `01-6 数据获取`（打通状态轴"流动→来源"）→ `01-8 交互与表单`（看两轴怎么交汇）

**第二遍（补视图轴细节与状态轴延伸）：**
`01-3 样式` → `01-7 路由`

**第三遍（补横切与落地）：**
`01-9 性能` → `01-10 可访问性多端` → `01-11 安全` → `01-12 架构工程化` → `01-13 可观测质量`

> 顺序非强制。每个支柱可独立阅读，遇到不懂的前置概念，顺"依赖↓"去查。
