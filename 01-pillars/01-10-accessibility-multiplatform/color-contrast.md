# 颜色与对比度（Color & Contrast）

> "灰色文字配浅灰背景"看着精致，但视障用户、色盲用户、强光下的用户根本看不清。颜色和对比度是 a11y 最容易被忽视、也最容易修复的部分。

## 是什么

- **对比度（Contrast）**：文字与背景的明暗差异。WCAG 有明确比例要求。
- **颜色无障碍**：不能只靠颜色传达信息（色盲友好）。

一句话边界：**a11y 的颜色规则 = 够对比 + 不只靠颜色。**

## 为什么：颜色 a11y 影响谁

| 用户 | 困难 |
|---|---|
| 低视力 | 低对比度看不清 |
| 色盲（约 8% 男性） | 分不清某些颜色，只靠颜色区分的信息丢失 |
| 强光/低端屏环境 | 所有人对比度感知下降 |
| 老年人 | 晶状体老化，对比度感知下降 |

## 怎么用：两条规则

### 规则 1：对比度达标（WCAG）
| 级别 | 正常文字 | 大文字（≥18px 或 14px 粗体） |
|---|---|---|
| **AA（最低要求）** | ≥ 4.5:1 | ≥ 3:1 |
| **AAA（增强）** | ≥ 7:1 | ≥ 4.5:1 |

- 灰色辅助文字常是重灾区（如 `#999` on `#fff` 只有 2.8:1，不达标）。
- 用工具检查：浏览器 DevTools 的对比度检查、WebAIM Contrast Checker、Figma 插件。
- 暗色模式同样要校验（暗背景上的灰字对比度）。

### 规则 2：不只靠颜色传达信息 ★
色盲（红绿色盲最常见）分不清某些颜色。如果信息只靠颜色区分，他们就丢失了：
```
❌ 表单错误：只把输入框边框变红（色盲看不出"红"和"正常"区别）
✅ 红边框 + 错误图标 + 文字"格式错误"（颜色+图标+文字，多通道）

❌ 图表：只有红绿蓝线条区分系列（色盲分不清）
✅ 不同颜色 + 不同形状/线型/标签

❌ 必填字段：只用红色标记
✅ 红色 + 星号(*) + "必填"文字
```
**原则**：颜色只能"增强"，不能"唯一"。每个颜色编码都要有非颜色冗余（文字/图标/形状）。

### prefers-contrast —— 尊重系统设置
用户可能在系统层开了"高对比度"。尊重它：
```css
@media (prefers-contrast: more) {
  /* 提供更高对比度的样式 */
}
```

## 常见坑

- ❌ **低对比度"精致设计"**：浅灰文字追求设计感，视障用户看不清。
  - ✅ 正例：用工具校验，至少达 AA。
- ❌ **只靠颜色表达状态**：错误只变红、成功只变绿，色盲丢失信息。
  - ✅ 正例：颜色 + 图标 + 文字。
- ❌ **暗色模式忘校验**：亮色模式对比够，暗色模式灰字不够。
- ❌ **链接和正文同色只靠下划线**：去掉下划线后链接不可识别，色弱用户找不到链接。
