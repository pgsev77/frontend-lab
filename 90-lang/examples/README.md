# 实战示例（v2-6）

> 把 v2 所有知识点串成可运行的项目。学完原理，看它"长在一起"是什么样。

## 示例

### [Dashboard 示例](./dashboard/)
一个最小但完整可运行的 Dashboard，串联：App Router 路由与布局、Server Components 首页、TanStack Query 数据缓存、Zustand 客户端状态与持久化、Tailwind 设计令牌与暗色模式、React Hook Form + Zod 表单、错误边界、骨架屏、404 兜底。

- [README.md](./dashboard/README.md) — 功能、运行方式、知识点对照
- **[KNOWLEDGE-MAP.md](./dashboard/KNOWLEDGE-MAP.md)** — ★ 每个文件/代码段对应 v1/v2 哪个概念（核心价值）
- 完整可运行源码：`package.json` / `next.config.mjs` / `tsconfig.json` / `tailwind.config.ts` / `src` 全套

> 这是学习用最小示例，非生产代码。重点是结构清晰、知识点可识别。每个关键文件顶部都有 `// 对应 v2: xxx` 注释，方便对照学习。
